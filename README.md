# Verzional Tap

Official Homebrew tap for apps and tools by [Verzional](https://github.com/Verzional).

## Casks

| App | Description | Installation |
|---|---|---|
| **CryptoNotch** | Real-time cryptocurrency ticker in your MacBook notch | `brew install --cask verzional/tap/cryptonotch` |

### Usage

Install directly:
```bash
brew install --cask verzional/tap/cryptonotch
```

Or tap the repository first:
```bash
brew tap verzional/tap
brew install --cask cryptonotch
```
